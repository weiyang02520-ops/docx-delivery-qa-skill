# DOCX Delivery and QA Skill

An Agent Skills-compatible workflow for creating, editing, integrating, and reviewing Word documents.

## What it protects

- original files and recoverable outputs;
- editable paragraphs, tables, images, sections, and hyperlinks;
- correct正文 placement and independent cover-page layout;
- factual provenance and user-verification boundaries;
- structural checks plus Word-compatible rendering QA.

## Status vocabulary

The skill uses `DRAFT`, `STRUCTURAL_QA_PASS`, `RENDER_QA_PASS`, `USER_CONFIRMATION_REQUIRED`, `STRUCTURAL_ONLY`, and `NOT_VERIFIED` to avoid overstating delivery quality.

## Installation

Copy this directory into an Agent Skills-compatible skills directory, or install the repository with the client-specific skill manager.
